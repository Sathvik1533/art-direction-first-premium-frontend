# Contributing

Thank you for helping improve Art Direction First — Premium Frontend System.

## What this project is

This repository is a reusable workflow for helping AI agents create original, high-quality frontend experiences. Contributions should improve the process, reduce generic AI output, strengthen visual and functional QA, or make the handoff clearer for people using different AI builders.

## Good contributions

Useful contributions include clearer prompts, stronger project-brief fields, better reference-analysis methods, additional accessibility checks, improved responsive QA, safer UI-library evaluation guidance, and examples that teach principles without copying a brand.

Please keep the system agent-agnostic. Do not add rules that only work for one provider, model, framework, or design tool unless they are clearly marked as optional guidance.

## Design contribution principles

Contributions should preserve these principles:

- Art direction precedes full implementation.
- Project truth precedes visual decisions.
- References provide principles, not templates.
- A project needs a distinct emotional premise and visual world.
- The marketing experience and real product workflow must share visual DNA.
- Visual concepts should be reviewed before full propagation.
- Accessibility, performance, truthful states, and functional behavior are part of quality.
- Component libraries must support the design system rather than replace it.

## Pull requests

Before opening a pull request, explain the problem, the proposed improvement, affected files, and how the change was validated. Keep changes focused and avoid adding duplicate guidance to `SKILL.md`; move detailed variant guidance into `references/` or reusable prompts into `templates/`.

If you add a third-party reference, asset, font, or library, include its URL and licensing considerations. Do not commit proprietary assets or copied website source.
