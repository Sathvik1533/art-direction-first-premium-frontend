## Repository purpose

This is a reusable process, not a LedgerLens-only style. A future project supplies its own product truth, references, UI direction/morphism, assets, icons, fonts, and quality bar. The process remains stable while each project creates its own visual world.

## Core workflow

Product truth → diagnosis → reference analysis → emotional premise → visual world → UI direction → three concepts → reject generic output → select direction → `DESIGN.md` → landing/entry proof → real workflow proof → screenshot review → full propagation → functional/responsive/accessibility QA → owner desired-outcome verification.

## LedgerLens status

LedgerLens is still in development. Antigravity produced and reviewed three visual concepts. Concept A — Cinematic Ledger was selected as the working direction. The concept harness and live landing preview showed a stronger deep-ink, mineral-evidence, Ledger Trace direction. The landing page is promising but not final.

The most important remaining LedgerLens design concerns are story and palette. The landing page still uses technical language too early, including throughput, parity, PostgreSQL numeric, Python Decimal, and contract invariant language. The next pass should lead with the human financial story: a payment was captured, less money arrived, LedgerLens shows exactly where the amount changed, explains why, and records what the reviewer decided.

The deep ink palette is a useful foundation but may read too much like a technical observability console. The next pass should test warmer and more semantically controlled color roles without discarding Concept A. The remaining product pages are still developing and must not be called complete until independently verified.

Directional review: `docs/LEDGERLENS_LANDING_REVIEW.md`.
